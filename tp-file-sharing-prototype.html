TP File Sharing

अपनी file upload करें, आगे चलकर उसकी unique link बनाएँ और WhatsApp या दूसरे social media पर आसानी से share करें।

यह अभी केवल prototype है। असली online upload के लिए बाद में server/storage जोड़ा जाएगा।

1. Upload

मोबाइल से PDF, document या अन्य file चुनें और upload प्रक्रिया शुरू करें।

2. Link

Final version में हर uploaded file की अलग shareable link बनाई जाएगी।

3. Share

Link को copy करके WhatsApp, Telegram, Facebook या दूसरे platform पर भेज सकेंगे।
